Python Data Processor

A small ETL-style command-line utility for CSV and JSON files. It cleans columns, removes empty rows, deduplicates records, filters data with pandas queries, and writes CSV or JSON output.

Run Locally

Install dependencies with pip install -r requirements.txt, then run:

python -m pydata_processor.cli summary data/sample.csv
